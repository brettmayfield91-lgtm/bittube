# BitTube branding

- `bittube-logo.jpg`: full logo (icon + wordmark), 1280x720.
- `bittube-icon.png`: square icon crop, source for favicon and PWA icons in `client/src/assets/images/`.
- Colors: indigo `#3B2F8F` to teal `#19C3B3`.

BitTube is a fork of PeerTube (Framasoft, AGPL-3.0). The original PeerTube logo and mascot remain in the repository under their original license.
